WEARHOUSE — MANAGER-ONLY DELIVERY CREATION (NOV 2026)

WORKFLOW:
1. Only a manager creates the delivery order. Select driver, products, quantities, destination, recipient, and date.
2. Employee sees the assigned order. They type the first characters of a serial number and select EXACT matching serial numbers for each product and quantity. They cannot create an independent order.
3. Serial selection goes to Pending manager approval. Manager reviews and chooses Approve or Reject. Rejection returns the order to the employee for correction.
4. Only after approval can employee upload 1–6 delivery photos plus a delivery note (PDF or image).
5. Manager reviews evidence and marks Completed. A manager can cancel an uncompleted order.

DATABASE:
- Database changes have already been applied to the connected Supabase Trade project.
- DO NOT rerun schema.sql, old migrations, or reset the database.
- Existing Trade tables, inventory and previous delivery requests were not intentionally removed.

GITHUB PAGES:
1. Unzip this archive. Upload/replace index.html, app.js, styles.css and config.js in the ROOT of the Wearhouse GitHub repository.
2. Commit the files on the branch configured for GitHub Pages.
3. Hard refresh the page (Ctrl+F5), then sign out and in again.
4. Manager: Delivery / Installation > + New delivery order.
5. Employee: Delivery / Installation > Choose serial numbers on an assigned order.
