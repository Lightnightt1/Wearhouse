NEW WORKFLOW
Manager:
- Adds products and their unique serial numbers using Staff / Admin and Serials.
- Sees incoming requests and notifications under Delivery / Installation.
- Opens delivery photos and delivery note, then confirms Completed (or cancels).

Delivery employee:
- Opens Delivery / Installation > + New delivery request.
- Starts typing a serial or product name; matching AVAILABLE serials appear.
- Selects one or multiple serials, enters destination, recipient, date and confirms.
- Request shows Pending; manager receives an in-app notification.
- Opens the pending request, uploads 1-6 delivery photos and a note (PDF or image).
- Request becomes Proof submitted; manager can confirm Completed.

SECURITY / DATA
- Serial selection is transactional; no serial can be actively reserved twice.
- Only authenticated, active delivery employees can create a new request.
- Only managers can confirm/cancel request and mark pieces delivered.
- Delivery evidence is stored in a private Supabase Storage bucket.
- Existing old delivery requests remain readable via the legacy UI.
- A single request can include multiple products and serials (up to 50).
