WEARHOUSE — GLASSMORPHISM WEBSITE UPDATE
=======================================

This is the actual Wearhouse website, not a static mockup.
It uses the existing Supabase Trade project and retains the existing
manager-created delivery orders, serial selection, approval/rejection,
proof upload, and automatic completion workflow.

NEW VISUALS
- Bell logo and matching favicon
- Glass-style sidebar, buttons, cards, modals, tables, notifications
- Teal frosted-glass dashboard following the approved screenshot design
- Responsive layout on desktop, tablet and mobile
- Dashboard metrics from actual warehouse data, not mockup statistics
- Activity chart from the latest recorded inventory changes

HOW TO PUBLISH ON GITHUB PAGES
1) Open the GitHub repository for the Wearhouse site.
2) Upload/replace these FIVE files in the web root:
   index.html
   app.js
   styles.css
   config.js
   favicon.svg
3) Commit the changes to the branch used by GitHub Pages.
4) Refresh the live website (Ctrl+F5 if your browser caches the old theme).

Do not upload desktop-preview.png or mobile-preview.png — those use sample
browser-only data for visual QA and are not part of the live website.
No Supabase SQL migration is needed for this visual change.
