WAREHOUSE REVIEW — targeted safe fixes

1) app.js: Supabase onAuthStateChange no longer awaits Supabase calls inside the auth callback.
   This prevents a documented potential deadlock on sign-in/sign-out/session refresh.
2) schema.sql + fix-rejection.sql: qualify the rejection_reason function parameter.
   This avoids the PostgreSQL column/parameter name conflict when rejecting a request.
3) README.md: documents the extra database RPC scripts needed by this frontend.
